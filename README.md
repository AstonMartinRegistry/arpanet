# AgentArpanet visualization

An interactive isometric view of two lab machines (rtx-01 and v100-01) on an AgentArpanet network: the hub, the WireGuard tunnel, each node's agent, its model and its collections. A walkthrough shows one `ask_peer` question travelling between the labs, step by step.

Open `index.html` in a browser, or view the GitHub Pages site. It is a single static page and loads three.js r128 from jsDelivr.

The two `netmap-*.json` files are illustrative netmaps, linked from step 1 of the walkthrough.
